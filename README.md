# Myanmar Keyboard — Phonetic (Romanized) Burmese for Windows

**Type Burmese anywhere by spelling words the way they sound.**
You type `mrnmaa` → you get `မြန်မာ`. Works in any app — Word, Chrome, Notepad, Facebook, chat, email — as a system-wide input method.

🌐 **Website / try it in your browser:** https://mechya.github.io/myanmar_keyboard_release/

---

## ✨ Features
- **Phonetic Romanized → Myanmar** — write Burmese using the English keyboard, no layout to memorize.
- **Standard Myanmar Unicode** — never Zawgyi.
- **Works system-wide** — types directly into any application.
- **Live suggestions** — a candidate list helps you pick the right word, and learns the words you use.
- **Letter variants** — `ta` offers both တ and ဋ in the list, so you rarely need Shift.
- **On-screen key chart** — every consonant, vowel sign, medial and tone mark (click to insert), plus Emoji and Sticker tabs.
- **No auto spaces** — Burmese is written without spaces between words, so spacing is always your choice.
- **Private by design** — runs fully on your PC. No keystrokes, usage data, or personal information are sent anywhere.

## ⌨️ Quick guide
| Type | Get | |
|---|---|---|
| `k` `kh` `g` `ng` … | က ခ ဂ င … | consonants (add `h` for aspirated) |
| `kaa` `ki` `kii` `ku` `ke` `ko` | ကာ ကိ ကီ ကု ကေ ကို | double the vowel to make it long |
| `kya` `kra` `kwa` `mha` | ကျ ကြ ကွ မှ | medials |
| `kan` / `kana` | ကန် / ကန | a final consonant gets ် automatically |
| `mii:` `ngaa.` `kaq` | မီး ငါ့ ကံ | `:`/`x` heavy tone · `.` creaky tone · `q`/`M` ံ |
| `mang;_galaapaa` | မင်္ဂလာပါ | `;` asat · `_` stacks the next letter |
| `/` `//` | ၊ ။ | clause / sentence marks |

While typing a word: **Space** picks the next suggestion, **Enter** commits, **Esc** cancels.
**Alt + `** switches between Myanmar and English.

## ⬇️ Download
| Platform | Where |
|---|---|
| Windows 10 & 11 | [Latest release](https://github.com/mechya/myanmar_keyboard_release/releases/latest) |

Run `MyanmarKeyboard-Setup-<version>.exe`, then press **Win + Space** and choose **Myanmar Phonetic (Romanized)**.
If Windows shows "Windows protected your PC", click **More info → Run anyway**.
